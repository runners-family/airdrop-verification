# Third-party material and modifications

The public replay includes selected account/type layout JavaScript from **@exponent-labs/exponent-sdk 0.9.29**, whose captured package declares **AGPL-3.0**. The original layout files are preserved in the evidence artifact with their own hashes. The GNU AGPL version 3 text is included in `LICENSES/AGPL-3.0.txt` (official GNU text SHA-256 `0d96a4ff68ad6d4b6f1f30f713b18d5184912ba8dd389f86aa7710db079abcb0`). The offline codec and PublicKey adapters replace network-capable runtime dependencies; they do not change those layout declarations. All 72 supported decoded strategy records and the 21 unsupported addresses were compared against the captured historical runtime, including every decoded field.

Meteora layouts are derived from projected official account IDLs captured from **@meteora-ag/dlmm 1.9.14** and **@meteora-ag/cp-amm-sdk 1.5.1**. The replay retains the account layout/discriminator/type fields needed by the calculation, while omitting documentation and unrelated metadata. Integer bin/liquidity and Decimal valuation functions are adapted from the historical RUNNERS derivation, which followed those SDK rules.

Symmetry beneficiary roles use selected legacy **0.1.80** IDL declarations, the captured on-chain legacy IDL, and the captured V3 SDK **1.0.22** deposit/withdraw instruction sources. The two V3 files are retained verbatim as reviewable source; the replay reads their discriminators, fixed account order and argument encoding without executing them. The legacy IDL is projected to the selected instruction/account names. No additional upstream licence grant is inferred from these captures.

Jupiter's replacement integer tick/liquidation implementation follows the historical **@jup-ag/lend-read 0.0.14** calculation. The original network-capable SDK bundle is not included. Every one of the 12,797 captured borrower output rows and the supply-only mint set were compared against that runtime with zero field differences. The captured package did not include a licence declaration or licence file; this notice does not infer one.

Historical RUNNERS Python derivation helpers are adapted to strict JSON, package-relative offline captures and the explicit privacy projection. Collection clients, credential loaders, transport URLs, old-list diff logic and live-network entry points are omitted. Precision contexts are local to each calculation. The Token-2022 owner constant typo in the historical Exponent helper is corrected to the official program address; all 263 relevant live captured mint accounts use classic SPL Token, so that correction changes no result.

No general licence choice for the owner's original material is asserted here. These notices and a successful replay are not a blanket licence-clearance statement for future publication.
